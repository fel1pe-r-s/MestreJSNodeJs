# 📂 Índice: `=this.file.name`

> [!ABSTRACT] Task Manager API - Clean Architecture
> Esta API foi desenvolvida para demonstrar o uso de **Clean Architecture** e **SOLID** no ecossistema Node.js.
> 
> ### ✨ Funcionalidades
> - **Autenticação**: Registro de usuários e login com JWT.
> - **Tarefas**: CRUD completo (Criar, Listar, Atualizar, Deletar).
> - **Segurança**: Senhas protegidas com BCrypt e rotas protegidas por Middleware JWT.
> 
> ### 🏗️ Arquitetura
> - **Domain**: Entidades e regras de negócio puras.
> - **Application**: Casos de uso (Use Cases) e lógica de aplicação.
> - **Infrastructure**: Implementações externas (Prisma, Fastify, Bcrypt).
> - **Shared**: utilitários como o padrão `Either` para tratamento de erros.
