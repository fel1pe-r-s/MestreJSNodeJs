# 📖 Manual do Usuário e Configuração
#Guia

Este guia contém tudo o que você precisa para usar este Vault com máxima eficiência.

---

## 💻 Configuração em um Novo Computador
Se você precisar abrir este Vault em outro PC:
1. **Instale o Obsidian**.
2. **Abra este Vault** (a pasta `Mestre`).
3. **Ative os Plugins**: Em `Settings` -> `Community Plugins`, ative todos.
4. **Sincronização**: No `Remotely Save`, selecione `Google Drive` e clique em **Auth**.

---

## 📂 Organização de Pastas e Caminhos
Para manter o Vault organizado, os seguintes caminhos estão configurados:

- **Templates de Notas**: `attachments/Templates`
- **Anexos e Imagens**: `attachments/imgs`
- **Novas Notas**: `00_Inbox` (Caixa de entrada)
- **Notas Diárias**: Salvas em `00_Inbox` usando o template `attachments/Templates/Template_Nota_Diaria`.

---

## 📂 Índices Automáticos (Zoottelkeeper)
O plugin cria arquivos de índice (ex: `Matemática.md`) usando o nosso **Template Premium**.
- **Título Dinâmico**: O título usa o código ``# 📂 Índice: `=this.file.name` ``.
- **Como ver**: No editor você verá o código, mas no **Modo de Leitura (Ctrl+E)** ou no **Live Preview**, o título aparecerá automaticamente com o nome da pasta.

---

## ⌨️ Atalhos de Teclado (Hotkeys)
Configurei os seguintes atalhos no Obsidian:

| Ação | Atalho | Botão Sugerido (G502) |
| :--- | :--- | :--- |
| **Página Principal (Dashboard)** | `Alt + D` | **G9** (Abaixo do Scroll) |
| **Inserir Template** | `Alt + T` | **G8** (Topo Esquerdo) |
| **Criar Nota Diária** | `Alt + N` | **G7** (Topo Esquerdo) |
| **Revisar Flashcards** | `Alt + F` | **Sniper Button** (Lateral) |
| **Alternar Modo de Leitura** | `Ctrl + E` | **Scroll Click** |

---

## 🖱️ Configuração Mouse Logitech G502 Hero
Para configurar seu mouse:
1. Abra o **Logitech G HUB**.
2. Associe os botões físicos aos atalhos acima.
3. **Exemplo**: Mapeie o botão `G8` para enviar as teclas `Alt` + `T`. Agora, um clique no mouse aplicará seu template de estudo instantaneamente!
