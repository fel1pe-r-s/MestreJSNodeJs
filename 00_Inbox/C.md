## 💡 O que é?
C é uma linguagem de programação procedural de propósito geral, criada em 1972 por Dennis Ritchie. É a base de muitos sistemas operacionais (Linux, Windows) e outras linguagens (C++, Python, Java).

## ⚙️ Como funciona?
Ela é compilada (transformada em código de máquina) e oferece acesso direto à memória via ponteiros, o que a torna extremamente eficiente mas perigosa se mal usada.

## 💻 Exemplo Prático
```c
#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}
```

## 🧠 Por que isso é importante?
- **Performance**: Controle absoluto do hardware.
- **Portabilidade**: Roda em quase qualquer arquitetura.
- **Base**: Aprender C ensina como o computador realmente funciona.
